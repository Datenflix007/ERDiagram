# ER Lab

Ein browserbasiertes Lernwerkzeug für ER-Modellierung: eigene Entitäten, Attribute
und Beziehungen anlegen, das Modell als relationale Tabellen oder OOP-Klassen
anzeigen, Datensätze aus Sprache ableiten und Normalisierung üben.

## GitHub Pages veröffentlichen

1. Dieses Repository nach GitHub pushen.
2. In **Settings → Pages** bei **Build and deployment** die Option
   **GitHub Actions** auswählen.
3. Jeder Push auf `main` veröffentlicht den Inhalt von `dist/`.
